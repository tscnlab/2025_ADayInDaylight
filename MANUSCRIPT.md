# Data Note manuscript

The prepared manuscript is available as
`manuscript/data_note.docx` and `manuscript/data_note.pdf`. Its synchronized
Quarto source is `manuscript/data_note.qmd`; the accompanying bibliography,
numeric citation style, Word reference document and figure sources are kept in
the same folder. The DOCX remains the checked submission artifact.

The root `checksums.sha256` covers the 18 reader-facing files in the Zenodo
dataset package.
The manuscript files are version-controlled separately and are not part of
that checksum manifest or the Zenodo dataset ZIP.
